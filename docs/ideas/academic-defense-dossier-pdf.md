# LapDoc Academic Defense Dossier & Code Explanation Report

## Problem Statement
How might we prove LapDoc is a genuine symbolic AI expert system through a styled, publication-ready PDF report linking academic theory directly to codebase implementation?

## Recommended Direction
A multi-chapter academic project report and code manual compiled to styled PDF:
1. Title Page & Abstract (Formal academic submission metadata).
2. Classical AI Expert System Architecture (Theory vs. LapDoc 5 subsystems).
3. Symbolic Representation & Knowledge Engineering (Decoupled JSON ontology).
4. Inference Engine Deep-Dive & Code Walkthrough (Forward chaining, certainty propagation in engine.py).
5. Explanation Facility & Boundary Detection ("Knowing what it knows").
6. Viva Defense Defense Guide (Answers to hostile examiner questions).
7. Appendices: Complete annotated code listings with callouts.

## Key Assumptions to Validate
- [x] Examiner values theoretical AI lineage (Buchanan/Shortliffe MYCIN model).
- [x] PDF rendering engine generates print-ready margins, page numbers, and highlighted code syntax.
- [x] File size stays email/LMS friendly (< 15MB) — actual output is 333 KB.

## MVP Scope
- Markdown source document with complete academic text and code annotations.
- CSS printable stylesheet with serif headings, monospaced code blocks, and page-break rules.
- Automated Python build script to compile document into publication-grade PDF.
- Verification pass ensuring every equation and code snippet matches repository state.

## Not Doing (and Why)
- No interactive web documentation (Evaluators require frozen PDF/paper submission).
- No line-by-line breakdown of frontend UI styling (Irrelevant to AI/expert system evaluation).
- No synthetic machine learning benchmarks (LapDoc is purely symbolic AI).
